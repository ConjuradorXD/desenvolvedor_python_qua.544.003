3 - o que é tupla, uma tupla é o segundo tipo de coleção que existe no python. é igual a lista que a gente estava vendo até agora mas ela é imutável, você não consegue inserir, ordenar, retirar nada que dentro dela, 
4 - A tupla serve para: ela garante a integridade dos dados, é um dos pilares das informações de dados, porque você não consegue criar um programa para alterar essas informações,
5 - como diferenciar uma lista de uma tupla, quando você ver uma lista com (), em vez de [], significa que é uma tupla.

6 - ficando assim:

```python
# lista chamada tupla, imutavel:

meses = (
    "Janeiro"
    "Fevereiro"
    "Março"
    "Abril"
    "Maio"
    "Junho"
)

for mes in meses:
    print(mes)
```
