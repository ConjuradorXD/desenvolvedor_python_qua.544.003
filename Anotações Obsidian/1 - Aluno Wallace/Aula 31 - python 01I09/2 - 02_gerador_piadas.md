1 - criar um gerador de piadas que traduz as piadas para o portugues.
2 - vamos exportar duas bibliotecas externas:
```python
pip install deep_translator pyjokes
```

3 - é obrigatorio fazer o requirements para fazer o deploy:

```python
requirements.txt
```

4 - Para desativar a venv usar o comando:

```python
deactivate
```

5 - versão do python:

```python
py -v
```

6 - vamos atualizar o python:

```python
py install -- update
```

7 - requirements.txt:

```python
pip freeze > requirements.txt
```
