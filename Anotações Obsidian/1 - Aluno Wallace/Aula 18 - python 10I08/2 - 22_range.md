3 - Vamos criar uma lista de nomes para o programa range.
4 - o range é como um contador de um laço for, ele conta quantas vezes o for vai percorrer, o range serve para percorrer uma lista até um determinado objeto da lista.

```python
for i in range(2):
    print(nomes[i])
```

5 - isso significa que o laço for vai percorrer a lista apenas o numero de vezes selecionado.
