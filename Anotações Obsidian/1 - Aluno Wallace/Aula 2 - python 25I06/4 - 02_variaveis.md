1 - criar uma nova pasta com o nome: 02_variaveis.
2 - novo arquivo chamado: main.py.
3 - Definição de variável: guardar um espaço do computador para salvar um numero.
4 - Como declarar uma variavel, podem ser tipos diferentes.

- 1 string: texto ex: texto
- 2 int: numero inteiro (idade) ex: 10
- 3 float: numero decimal. ex: 1.80
- 4 bulet: (true,false) sempre em maiúscula.
 
---------------------------------------------
nome = "Alex Machado"  (string)
idade = 41 (int)
altura = 1.72 (float)
programador = true (bulet)

-----------------------------------
5 - Para fazer comentários # antes do comentário
6 - Três aspas para múltiplas linhas.
7 - para exibir a variavel:

- print(nome)
- print(idade)
- print(altura
- print(programador)

8 - para dar play apertar: ctrl + f5, escolher a opção: python debugger, se der certo aparece no terminal o que foi escrito.
